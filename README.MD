# Quiz Game

## Start
Run ```python main.py```

You will be asked a series of questions from ```questions.py```
<br><br>
after each question you will be prompted for answer, e.g.
<br><br>```Answer: <your answer> ```

At the end your score will be tallied and displayed, e.g.
<br><br>
```Congrats! Your final score if 5```
